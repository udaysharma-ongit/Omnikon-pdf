About the project :
<br>
SoilSaathi is a smart soil health and fertilizer advisory system designed for smallholder farmers. It combines a low-cost portable device (measuring pH of N, P, K, Organic Carbon, and Moisture via an ESP32 microcontroller) with an via bluetooth mobile app. The system processes these measurements using ICAR/IISS interpretation ranges to generate instant, crop-specific fertilizer dosage recommendations.
<br><br>
Applications of this project :
<br>
Instant Results: Delivers accurate soil guidance within minutes directly in the field, compared to 6–8 months for government Soil Health Cards or expensive private lab tests (₹1,200–₹3,000 per sample).
<br>
Actionable Guidance: Translates raw test numbers into specific dosage plans tailored to the farmer's crop, season, and irrigation type.
<br>
Cost & Yield Efficiency: Targets imbalanced fertilizer usage, helps cut input costs, prevents soil degradation, and improves crop yields.
<br>
Accessibility: Built with a vernacular, icon-first UI for low-literacy farmers and works offline to handle rural connectivity gaps.
<br><br>
How users can get started :
<br> 
Collect & Test: Take a soil sample in the field and test it using the portable sensor device.
<br>
Connect: Pair the device to the React Native mobile app via Bluetooth to read in parameter data.
<br>
Receive Advisory: Select the specific crop, yield target, and irrigation type to generate a local-language dosage plan instantly.
<br><br>
Availability of help for users :
<br>
In-App Expert Access: The mobile application includes contacts for agricultural experts who provide real-time fertilizer and crop recommendations.
<br>
Local Networks: Distribution and ongoing user support are routed through local Farmer Producer Organisations (FPOs), Krishi Vigyan Kendras (KVKs), and agri-dealers.<br><br>
